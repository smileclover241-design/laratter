# Laratter（ブックマーク機能追加版）

受講番号：6th37
氏名：西井 彩

## 1. プロダクトの紹介

講義で作成した SNS アプリケーション「Laratter」に、**ブックマーク機能**を追加しました。

* 各 Tweet をブックマークとして保存できる
* 保存した Tweet を「保存したツイート」一覧から確認できる
* 保存した Tweet のブックマークを解除できる
* サイドバーから「保存したツイート」一覧へ移動できる
* ブックマークした Tweet のみが保存一覧に表示される

ブックマーク機能を追加した理由は、気になった Tweet や後から見返したい Tweet を保存できるようにすることで、SNS アプリケーションとしてより便利に利用できると考えたためです。

また、ブックマーク情報をデータベースに保存することで、ユーザーごとに保存した Tweet を管理できるようにしました。

## 2. こだわった点・苦労した点

* Tweet と User の多対多のリレーションを利用して、ユーザーごとにブックマークを管理できるようにした
* 同じ Tweet を何度も保存しても重複しないように `syncWithoutDetaching` を使用した
* 保存した Tweet を一覧表示できる専用ページを作成した
* サイドバーに「保存したツイート」を追加し、いつでも一覧へ移動できるようにした
* 保存解除にも対応し、一覧から削除できるようにした
* ブックマーク機能について Feature Test を4つ作成し、保存・解除・一覧表示・未保存Tweetの非表示をテストした
* 最終的に全52テスト、132 assertionsがすべて成功することを確認した

## 3. 操作方法

1. トップページからログインする
2. 「Tweet一覧」を開く
3. 任意の Tweet の「🔖 bookmark」を押す
4. サイドバーの「保存したツイート」を押す
5. 保存した Tweet が一覧に表示されることを確認する
6. 「🔖 保存解除」を押す
7. 「保存したツイート」を再度開き、保存解除した Tweet が一覧から消えていることを確認する
